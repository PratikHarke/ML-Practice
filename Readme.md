# ML-Practice

A collection of hands-on Machine Learning implementations using Python, NumPy, pandas, and scikit-learn. This repository documents my learning journey through regression, classification, model evaluation, cross-validation, and exploratory data analysis.

## 📁 Repository Structure

```text
ML-Practice/
├── Linear_Regression(Single_Variate)/
│   └── Simple linear regression using one feature
├── Linear_Regression(Multi_Variate)/
│   └── Multiple linear regression using multiple features
├── Linear_regression(Boston_Dataset)/
│   └── Regression using the Boston housing dataset
├── Ridge_and_Lasso/
│   └── Regularized regression with hyperparameter tuning
├── Logistic_regression/
│   └── Classification using logistic regression on the Iris dataset
├── Decision_Tree/
│   └── Decision Tree with pre-pruning and post-pruning
├── Cross-Validation/
│   └── Model evaluation using cross-validation techniques
└── EDA/
    ├── AutoViz_Plots/
    │   └── Automated EDA visualizations
    ├── Autoviz_EDA.py
    ├── SweetViz_EDA.py
    ├── SWEETVIZ_REPORT.html
    └── california_housing.csv
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/PratikHarke/ML-Practice.git
cd ML-Practice
```

### 2. Install Dependencies

```bash
pip install numpy pandas scikit-learn matplotlib seaborn
```

Install the EDA libraries separately:

```bash
pip install autoviz sweetviz
```

### 3. Run the Programs

Open any Python file in VS Code or your preferred IDE and run it.

For Python files containing cell markers, use the VS Code Python Interactive Window.

## 📊 Exploratory Data Analysis

The `EDA/` directory contains practical experiments using automated EDA tools.

### AutoViz

AutoViz is used to generate visualizations for exploring:

- Feature distributions
- Relationships between variables
- Correlations
- Dataset patterns

### SweetViz

SweetViz is used to generate interactive HTML reports containing:

- Dataset summaries
- Feature statistics
- Missing-value information
- Feature relationships
- Visual data analysis

The California Housing dataset is used for practicing exploratory data analysis and visualization.
